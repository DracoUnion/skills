# 文案去重（derep）

## 目标

把一段素材改写为**表述与素材明显不同、核心观点一致**的全新文案，且与素材的 n-gram 重复度低于阈值。适用于自媒体文案、教程、笔记等的洗稿与去重场景。

## 输入与输出

- 输入：`.md` / `.txt` 素材文件，或包含素材的目录。
- 输出：与源文件同目录的 `{basename}_derep.{ext}`，例如 `note.md` → `note_derep.md`。
- 幂等：若输出文件已存在，跳过该文件；支持断点续跑。

## 工作流

1. **确定输入文件**
   - 文件：直接处理。
   - 目录：列出目录下所有 `.md`/`.txt`（需要遍历子目录时递归）。
   - 排除：跳过名字含 `_derep.` 的文件；跳过文件名匹配排除正则的文件。
2. **分块**
   - 每块大小上限默认 8000 字符，以换行分片、尽量在段落边界切分。
   - **代码块（```` ``` ````...```` ``` ````）、图片（`![..](..)`）、公式块（`$$..$$`）必须整体保留在同一块内，不可拆散。**
3. **每块处理**（可并行）：
   - **占位**：把代码块/图片/公式块替换为 `[PRE0]`、`[PRE1]`… 占位符，并记住映射。
   - **改写**：按下方【改写要求】生成全新文案。
   - **检测**：运行脚本计算 n-gram 重复度，并检查 `[PRE*]` 占位符是否完整。
   - **修复**：不达标则按【修复要求】重写，循环最多 3 轮。
   - **还原**：把 `[PRE*]` 占位符还原为原始代码块/图片/公式。
4. **合并输出**：各块结果用空行（`\n\n`）连接，写入输出文件。

## 改写要求

- 核心观点与素材保持一致，不遗漏、不曲解素材中的关键信息与结论。
- 表述必须与素材**明显不同**：尽量更换句式、同义词与行文顺序，避免与素材出现连续的相同或高度相似短语。
- 语言自然流畅、富有吸引力，符合自媒体发布场景。
- 遇到 `[PRE*]` 标志必须完全保留，不遗漏、不新增。

## 重复度检测（确定性计算）

n-gram 重复度必须用脚本精确计算，不要目测：

```
python scripts/ngram_check.py metrics --source <源文件> --copy <改写文件> --n 3 --threshold 0.4
```

指标含义：

| 字段 | 含义 |
|------|------|
| `ngram_similarity` | n-gram Jaccard 相似度：两文共有 n-gram 数 / 并集数，0-1 |
| `ngram_coverage` | 覆盖率：共有 n-gram 数 / 改写文 n-gram 总数，0-1 |
| `repeated_ngrams` | 两文共有的 n-gram 列表，即需要规避的重复片段 |
| `is_duplicated` | `similarity >= 阈值` **或** `coverage >= 阈值` 即为重复 |
| `missing_blocks` | 素材中的 `[PRE*]` 未出现在改写文中 |
| `unknown_blocks` | 改写文出现了素材没有的 `[PRE*]` |

默认参数与 CLI 一致：`n=3`、`threshold=0.4`，可根据需求调整（窗口越大对连续重复越敏感）。

## 修复循环

检测不通过（`is_duplicated=true`，或 `missing_blocks`/`unknown_blocks` 非空）时，重写当前文案：

- 重点规避 `repeated_ngrams` 中列出的片段，用完全不同的措辞和句式替换它们。
- 尽量更换句式、同义词与行文结构，与素材彻底区分开。
- 补齐缺失的 `[PRE*]`，删除素材中不存在的 `[PRE*]`。
- 保留核心观点不遗漏、不曲解；语言保持自然流畅。
- 重写后重新检测；最多 3 轮，达标即停。

## 分块工具

需要按确定性逻辑分块时：

```
python scripts/ngram_check.py chunk --file <源文件> --limit 8000 [--out-dir <目录>]
```

脚本会先按行拆分（代码块整体保留），再按 `limit` 合并分组；`--out-dir` 时把每块写入 `000.md`、`001.md`… 便于逐块处理。

## 质量检查清单

- [ ] 每块改写后 `similarity < 阈值` 且 `coverage < 阈值`？
- [ ] `missing_blocks` 与 `unknown_blocks` 均为空？
- [ ] 核心观点无遗漏、无曲解？
- [ ] 输出文件中各块之间用空行连接？
